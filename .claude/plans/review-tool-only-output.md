# 구현 계획: Review 모드 도구 전용 출력

## Context

에이전트가 review 모드에서 분석 결과를 채팅 텍스트로 출력하여 DB에 저장되지 않는 문제.
프롬프트를 강화하여 도구 호출을 강제하고 텍스트 출력을 금지해야 함.

## 변경 사항

### 1. `backend/app/agent/prompts.py` — REVIEW_MODE_PROMPT 재작성

핵심 변경:
- **절대 규칙 섹션 추가**: "텍스트로 교정/드릴을 출력하면 안 됨" 명시
- **출력 형식 제한**: 채팅 텍스트는 짧은 상태 메시지만 허용
- **처리 플로우를 단계별로 명확화**: 입력 분석 → extract_corrections → generate_drill → 완료 메시지
- **금지 사항 명시적 나열**: "다음은 하지 마세요" 섹션

프롬프트 구조:
```
## 현재 모드: 수업 후 복습

## ⚠️ 절대 규칙
- 분석 결과는 반드시 도구로만 출력
- 텍스트로 교정 목록/드릴 나열 금지
- 채팅은 짧은 상태 메시지만

## 처리 플로우
1. 입력 분석 (내부)
2. extract_corrections 호출
3. generate_drill 호출
4. 완료 메시지

## 금지 사항
- 텍스트로 오류 분석 결과 출력
- 텍스트로 드릴 문제 출력
- 도구 호출 없이 분석 완료 선언

## 허용되는 텍스트 출력
- "분석 중입니다..."
- "N개 오류 발견, 드릴 생성 중..."
- "분석 완료"
```

### 2. `backend/tests/test_mode_splitting.py` — 테스트 추가

- 프롬프트에 "금지" 또는 "하지 마세요" 키워드 포함 확인
- 프롬프트에 "반드시 도구" 키워드 포함 확인
- 프롬프트에 "텍스트로" + 금지 표현 포함 확인

## 검증

1. `cd backend && .venv/bin/python -m pytest tests/ -v` — 전체 통과
2. `cd frontend && npx vitest run` — 전체 통과
